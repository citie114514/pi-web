## 失败史（这是本次最重要的输入）

| 版本 | 做法 | 被否的原因（实测） |
| --- | --- | --- |
| v1 | 深色 + 蓝，8 镜 30s | 字号 136–210px 过大（画面只剩字）；无配乐；动画单一；篇幅短 |
| v2 | 深色 + 蓝，10 镜 48s，五张镜头卡 | 主视觉是「截图装在窗口里 + 一行大字卡」，**运动只发生在转场的 1–2 秒，中间 3–5 秒是静止的**；全片 6 级字号只用了 13 次；同一张截图出现两次且视角相同 |
| v3 | 纸墨朱砂（换皮不换骨） | 用户原话：「这个动画我有点不满意」。抽 5 帧检查，其中 3 帧是静止构图 —— 换了配色，运动语言没变 |

**根因诊断（必须在你的提示词里被显式解决）**：
三版的共同病根不是配色、不是字体大小，而是**构图形态**——每一镜都是「一张静止的截图 + 一行字」，
再把镜头交给转场。这类片子在任何参数下都像 PPT 换页，因为**画面上没有持续发生的事**。

已做的 7.5 秒三选一样片（`MotionProof`）验证了三种**可用的运动语言**，可以继承、也可以推翻：

- **A 蓝图技术流**：深底 + 持续绘制的网格 + 准星跟随 + 尺寸标注 + 等宽字解码
- **B 明亮编辑流**：浅底 + 超大 Noto 900 逐字掩码揭幕 + 2.5D 翻转落位 + 分层视差
- **C 终端流**：纯黑 + 字符流打字 + 窗口从终端行「长」出来

## 你要产出的提示词必须包含的章节

**1. 一个决定，不是一张菜单。**
先给这支片子一句「气质定义」（例如：*它应该像一件被摆上工作台、正在被组装的器物*），
再点名 2–3 支参考片（真实存在的产品片/工作室作品），并写出**你从每支里具体借了什么技术**
（不是「学习了它的氛围」，而是「借了它的 XX 手法，因为……）。然后给出唯一的视觉方向。

**2. 一套完整的设计令牌**，全部是具体值：色板（每个 HEX + 用途 + 像素占比上限）、
字体（家族/字重/字号阶梯，相邻比 ≥1.25）、间距基数、圆角、阴影、光位、
缓动曲线（cubic-bezier 数值）与时值。

**3. 一个贯穿全片的「主体隐喻」**：让 10 个镜头是同一件事的不同阶段，
而不是 10 张互不相关的大字卡。写清楚这个隐喻在第一镜、中段、结尾分别长什么样。

**4. 逐镜分镜表**：8–12 个镜头 ×（时长帧数、**画面上一直在动的是什么**、
它在动的原因、首帧/中帧/末帧各长什么样）。**每一镜都必须回答"这一镜里什么在持续运动"**——
答不出来的镜头就是静止帧，必须重设计。

**5. 可验证的审美标准**（每条都能从 MP4 或静帧量出来，附测量方法）：
- **运动连续性**：把成片缩到 480×270 灰度，逐帧算平均绝对差；**不允许出现连续 >1.0s
  的帧差 <0.3 的静止段**（唯一的例外是刻意设计的静止，且全片 ≤2 处、每处 ≤0.8s）
- **卡点**：先对 BGM 做起音检测，产出 `beat-grid.json`；≥80% 的切点落在最近起音 ±3 帧内
- **截图可读性**：截图内 UI 正文字号换算到画面后 ≥12px；同一张截图不得以相同视角出现两次
- **字号**：≤6 级、相邻比 ≥1.25、主标题占画宽 3–7%
- **强调色**：ΔE≤10 的像素 ≤5%/帧；单帧色相 ≤3 种（中性不计）
- **构图**：每镜 5–12 个元素、主元素占画面 ≥25%、至少 3 个深度层
- **转场**：每一次转场都要写清"为什么是这种转场"（内容关系），禁止"按位置分配转场类型"

**6. 执行顺序**：① 设计令牌 + 2 支 3 秒动态样片（不同手法）出片给人看
② 确认后铺 8–12 镜 ③ 节拍对齐 ④ 渲染两版。每阶段结束停下等确认，并附数字。

**7. 交付物契约**：改哪些文件、每阶段要交什么证据（设计令牌表、样片 MP4、静帧、
`beat-grid.json`、运动连续性曲线、卡点命中率、两版 MP4、`package.json` diff 必须为空）。

**8. 反模式清单**（至少包含）：静止截图配大字卡；用转场制造节奏感；SimHei 当主标题；
「一张图 + 一行字」重复 10 次；为卡点而卡点导致语义断裂；把"更快"当"更好"；
用手搓假 UI 代替真实截图；只有一种运镜（全片都在 scale 1.0→1.06）。

## 写作纪律

- 每个形容词后面必须跟数字、色值或一条可跑的命令；跟不上的形容词删掉。
- 不允许出现「高级感」「电影感」「更有设计感」这类无法验收的词。
- 允许大胆：可以推翻 A/B/C 三种样片，可以说「不要大字卡」。
- 中文输出，1500–2200 字，二级标题分节，可直接整段粘贴给编码 agent。

## 输出格式

1. 5 行以内：你选的方向 + 你认为最关键的三条规则 + 为什么它们能根治「静止截图」这个病。
2. 一个代码块，标题「交给编码 agent 的提示词」，内容是完整提示词。
3. 一张自检表（3 列：规则 / 如何测量 / 它解决了失败史里的哪一条），6–8 行。

5. 这套视觉与「深色开发者工具」的产品本体是什么关系？写清取舍，不许含糊。
